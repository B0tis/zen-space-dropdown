# Publishing status

The official [zen-browser/theme-store](https://github.com/zen-browser/theme-store) is **archived (read-only)** as of 2026-07-23, so the old `[create-theme]` issue workflow no longer works.

## Current distribution

1. **GitHub repo:** https://github.com/B0tis/zen-space-dropdown
2. **Import file:** `space-dropdown.zen.json` (Zen Settings → Mods → Import)
3. **Manual local install:** copy `chrome.css` + `preferences.json` into `chrome/zen-themes/<id>/` and register in `zen-themes.json`
